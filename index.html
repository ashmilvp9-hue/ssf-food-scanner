Admin-only tool

Food coupon scanner

This page opens separately because Google Apps Script does not permit camera access inside its HTML sandbox. Scan a student's food-coupon QR (not the website QR). The admin page validates the token against the registration sheet.

Open this scanner from Admin panel → Food scanner. Then tap Start camera and allow camera access.

If prompted, choose the rear camera. Camera permission is required. A successful coupon is accepted only once; this page itself does not decide whether food is allowed—the connected admin page does.
